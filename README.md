# Colon Emoji

A Chrome extension that brings Discord-style emoji typing to text boxes across the web.
Type `:smile:` and it becomes 😄, or type `:sm` and pick from a menu.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the `extension` folder inside this project.
4. Refresh any tabs that were already open.

After editing the code, click the reload icon on the extension's card, then refresh your tabs.

## Using it

| You do | What happens |
| --- | --- |
| Type `:smile:` | Converts to 😄 as soon as you type the closing colon |
| Type `:sm` | Opens the menu |
| `↑` / `↓` | Move through the menu |
| `Enter` or `Tab` | Insert the highlighted emoji |
| `Esc` | Dismiss the menu for this shortcode |
| Click a row | Insert that emoji |

Details worth knowing:

- **One letter:** the menu opens but nothing is highlighted, so `:D` then `Enter` still sends
  your message. `Tab` or an arrow key picks an emoji.
- **Ordinary colons** are ignored when they follow a letter, number, slash or another colon,
  such as `12:30`, `http://` and `a:b`.
- **Undo** (`Cmd/Ctrl+Z`) brings the shortcode back and leaves it as text.
- **Ranking:** emoji you use often move up the menu.
- **Flags** use the `flag_` prefix, such as `:flag_us:`.
- **Password fields** are always skipped.

## Custom emoji

Click the toolbar icon, then **Custom emoji**, to upload an image and name it. After that,
`:its_name:` works like any other emoji, and yours appear first in the menu with a thumbnail.

A custom emoji can't be text, so it's attached as a small image, the same as pasting a file. The
other person doesn't need the extension. On Messenger, it sends as its own image, separate from
any text in the same message.

- **Size:** images are shrunk to 64px. Messenger shows images at about their real size.
- **Transparency:** transparent areas can show as white once sent on Messenger, depending on the image and chat.
- **GIFs:** kept as they are, up to 1 MB. Messenger makes people click to play them.
- **Where it works:** boxes that accept pasted images. If a box ignores the image, the shortcode
  stays and a short note appears. Single-line inputs such as search bars don't offer them.
- **Storage:** kept in this browser only, with no sync between computers.

## Settings

Click the toolbar icon to turn the extension off, or off for the current site. It starts off on
discord.com, app.slack.com and github.com, which have their own emoji menus.

## Privacy

Nothing leaves your browser. The extension makes no network requests. Chrome will warn that it
can read data on all sites, because it has to see what you type in order to work. Your per-emoji
use counts are kept in local extension storage, and your settings in Chrome sync storage.

## Known limitations

- Text inside shadow DOM components isn't detected, which may affect some sites' editors.
- Canvas-based editors such as Google Docs aren't supported.
- Skin tone variants aren't included yet.

## Development

```bash
npm install
npx playwright install chromium
npm test
```

`npm test` runs the search unit tests, then loads the real extension into Chromium and types into
a test page with Lexical, React and plain editors.

- `extension/src/content.js`: detection, insertion and the menu
- `extension/src/search.js`: trigger matching and ranking
- `extension/src/emoji-data.js`: generated by `npm run build:data` from `emojibase-data`
- `extension/popup/`: toolbar popup
