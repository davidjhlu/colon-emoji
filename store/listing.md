# Chrome Web Store listing

## Name
:emoji

## Summary
Type :smile: in any text box on the web to insert an emoji, with autocomplete as you type.

## Category
Tools

## Language
English

## Description

Stop hunting through emoji pickers. :emoji lets you type emoji the fast way, in text boxes across the web.

TYPE IT
Type :smile: and it turns into 😄 as soon as you finish the shortcode.

OR PICK IT
Start typing :sm and a small menu appears. Use the arrow keys, then Enter or Tab to insert. Esc closes it. The emoji you use most move to the top.

ADD YOUR OWN
Upload your own images, give them a name, and use them the same way. Custom emoji are attached as a small image, so the person you're chatting with doesn't need this extension. They work in boxes that accept pasted images, and they send as an image, not inline with your text.

STAYS OUT OF YOUR WAY
• Ordinary colons like 12:30 and http:// are ignored
• :D then Enter still sends your message
• Undo brings your shortcode back
• Turn it off everywhere, or just on one site
• Password fields are always skipped

PRIVATE BY DESIGN
:emoji needs to read what you type to spot shortcodes, so Chrome will show a warning about reading data on all sites. Your text is checked on your device and is never saved or sent anywhere. The extension has no server and makes no network requests. Nothing runs until you agree on the first-run page.

Doesn't work everywhere: editors that draw their own text, such as Google Docs, aren't supported.
